# 完了を3段階で判定する

## A：アプリ実装
- typecheck / build / 重要なテストが成功。clean install手順が再現可能。
- 4資格を選択でき、同梱オリジナルサンプルで4形式を正しく採点できる。
- multipleは選択順で正誤が変わらず、1項目余計に選べば不正解になる。
- シャッフルしても正解ID・解説・履歴が正しく対応する。対応付けの候補再利用規則も守る。
- 練習は確定後直下に解説、模擬は提出前に解説が出ない。
- 誤答に加えて、正解だが「あやふや」とした問も復習に入る。
- メモ・回答・ブックマーク・出題順がリロード後も残る。
- 模擬を閉じて再開した際に絶対期限を正しく扱い、期限切れは一度だけ提出する。
- 初回/直近/全履歴を区別し、問題改訂後も過去回答を再現できる。
- パック再取り込みで増殖しない。破損ZIPや不正IDの取り込みで既存データを壊さない。
- 画像入り完全バックアップ→空の保存領域へ復元→問題数・画像・履歴・メモ・途中セッションが一致する。
- 異なる端末の履歴統合で同じanswerId/sessionIdを重複しない。
- IndexedDB書き込み失敗、空問題集、選択数違い、画像不足を処理できる。
- HTML/Markdown/ZIPで任意コード実行や外部画像読み込みが起きない。
- 375px/PCで長文・図表・matchingが読め、キーボード操作も可能。PWAは初回準備後にオフラインで動く。

## B：教材準備
- 原本が提供されている場合だけ、期待472問との実数比較を行う。受領ファイルと対象件数を明記。
- 元の別シートからの二重取り込みがない。
- questionId、原ID、出典、図表ID、対応付け候補の対応が保たれる。
- 英語原文236問は翻訳済みか、未翻訳/隔離かを全件報告する。日本語原文236問も取り込み漏れがないか報告する。
- 全問の選択肢・正解・正誤解説・補足・注記・背景・図表を保持。無い説明は原文未収録と区別する。
- 図表50枚、補足講義10件は期待値。実体の有無と関連付けを検証。図表を含む問題は画像照合。
- Matthew CCDV-F5.9等の矛盾を通常出題から隔離。全件をreadyにするために不明な正解を創作しない。
- 翻訳完了と技術的な解答検証の完了を別々に報告する。
- 原本不足でもAは完成させ、Bが未完了である理由と必要ファイル名を明記する。

## C：公開と私的データ
- repoサブパス上で直接URL・再読み込み・画像・PWAが動く。
- 公開用distに原本、私的問題パック、翻訳チェックポイント、履歴、秘密情報が含まれない。
- .gitignoreだけに頼らず `git ls-files` と成果物一覧も確認。既に追跡済みのファイルはignoreだけで非公開化できない。
- デプロイ許可がある場合にPages URLの稼働を確認。無ければworkflowと手順を完成させ未公開と報告する。
- アプリ公開、実教材全件の日本語化、本人の端末への問題取り込みは別段階として、何が完了したか明確にする。
