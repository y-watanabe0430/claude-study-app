# アプリ要件

## 必須画面
1. ホーム：資格ごとの問題数・未学習・要復習・最新正答率。データ未登録の資格は0件と取り込み案内を表示。
2. 問題管理：出典、分野、検索、翻訳・レビュー状態、類似グループ、図表欠落を確認。全件準備完了と隔離件数を分ける。
3. 学習設定：資格、教材、分野、問数、初回/未回答/誤答/あやふや/ブックマーク、問題順、選択肢順、時間制限を選ぶ。
4. 解答：背景・問題・図・選択肢・選択数を日本語表示。「確定」は有効な回答でのみ可能。確定前に戻って回答変更可能。
5. 練習の解説：自分の回答、正解、各選択肢の理由、補足、次点、注記、図表、出典、メモを問題直下に表示。確定後の選択変更で履歴を改変しない。再挑戦は新しいattempt。
6. 模擬の結果：提出まで解説非表示。未回答一覧と提出確認、タイムアウト時の自動提出、各問の時間、分野別・出典別成績、全問振り返り。
7. 復習：誤答、あやふや（正解でも対象）、ブックマーク、期限が来た問題を絞り込む。簡単な1/3/7/14日の再出題規則を文書化し、「理解した・あやふや・分からない」で更新する。
8. 履歴：全受験・全回答を残す。初回成績と直近成績を別表示。現在の問題が改訂されても当時の問題・回答・正解のスナップショットで振り返る。
9. 設定：JSON/ZIP取り込み、完全バックアップ、復元、文字サイズ、任意の原文表示、保存状態の説明。全データ削除は明示的な確認を必須にする。

## セッション・採点
sessionには資格・モード・パックversion・問題IDとrevision・固定済み出題順・固定済み選択肢順・開始/期限/提出時刻・状態を保存。リロードしても順番と回答を維持する。
タイマーはDate.now()と絶対期限で計算し、タブがバックグラウンドでも経過時間を落とさない。休止可能なのは練習のみ。模擬は閉じても期限が進む。
各回答はanswerId・sessionId・questionId・revision・表示順・選んだID・正解ID・正誤・所要時間・自信度・時刻を保持。
模擬採点は全出題数を分母とし未回答は不正解。分野集計も未回答を含める。single/multiple/matching/orderingは完全一致を原則にし、対応付けの部分一致は補助表示のみ。
模試の正答率（%）と本番のスケールスコアを換算しない。「正答率80%を学習目標にする」等はユーザー設定と明記。資格の問題数や時間は教材設定として持ち、最新公式情報を参照できるようにする。

## UI
日本語、375px以上のスマホとPC。横スクロールを本文に発生させない（コードや表のみ個別スクロール可）。タップ領域44px以上。図表は拡大表示し、図の日本語altも読むことができる。
色だけで正誤を区別しない。選択肢はradio/checkbox等のアクセシブルな部品を使う。長文で下部ボタンが本文を隠さない。
学習画面にJSONやDBやGitHubの実装説明を混ぜない。データ移行画面では、端末内保存・消失可能性・手動バックアップを簡潔に説明する。

## 保存と無料運用
IndexedDBにパック・画像Blob・メモ・セッション・回答を保存。書き込み失敗や容量超過を表示し、保存できていないまま「保存済み」と表示しない。
端末・ブラウザ間の自動同期なし。バックアップを使って移す。同時に別端末で学習した履歴もIDで統合できる。アプリの公開URLを変えると保存領域が変わる点もREADMEへ記載。
外部解析、広告、外部AI通信なし。静的asset以外のネットワーク要求を原則不要にする。画像取り込み・描画もローカルで完結させる。
