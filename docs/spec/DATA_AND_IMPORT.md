# データ変換とインポート

## 旧Excel
主シートは「問題一覧」。想定列：管理ID、教材、原問題番号、言語、分野、シナリオ、共通背景、設問形式、指定選択数、問題文、選択肢A〜E、対応付け候補、原文の正解、正解内容、正解の解説、誤答の解説、補足解説、次点の選択肢、次点が誤りの理由、図表ID、問題PDFページ、解答PDFページ、カード開始行、出典URL、保存日、原文選択肢の表示順、保存時の注記。
実ファイルの列名・型を確認して対応表を作る。空欄は「原文にない」か「変換で欠けた」かを区別する。誤答解説を明確に対応付けできなければ推測せず、原文のまとまりのまま supplemental.wrongExplanation に保存し、人が確認できるようにする。

## IDと選択肢
question.id は `資格:出典:原問題ID` とし、MP-1.1など既存管理IDもsource.originalIdで保持。翻訳・表示順変更でIDを再発行しない。選択肢は固有IDを持ち、正解は文字ラベルや配列位置ではなくIDで参照する。元のA〜EもoriginalLabelに保持。
みのるん版の旧Excelは表示順の並べ替えと正解記号の置換が済んでいるため、orderを再適用しない。元HTMLから直接変換する場合だけorderとansの関係を検証して一度適用する。選択肢に「AとB」等の位置参照がある場合はシャッフル不可にする。

## 形式
- single：ちょうど1選択。指定数と正解数が一致する。
- multiple：指定された数を選択。順不同で集合が完全一致したときだけ正解。
- matching：左側の各小設問ID→右側候補IDのマップ。候補の再利用可否は原文どおり。不明ならneeds_review。
- ordering：項目IDの順序が完全一致すると正解。既存教材にこの形式があると決めつけず、拡張・サンプル用として対応する。
matchingやorderingはスマホのプルダウン・上下ボタンで回答でき、ドラッグ操作を必須にしない。

## 日本語
利用者から提供された利用可能な教材を対象に翻訳。元英語はoptional originalTextに保存し、通常画面にはjaの各項目を使う。API名やJSONキーは翻訳しない。英語が混ざったことだけでエラーにするASCII判定ではなく、文章部分が日本語か、否定・数値・選択数・選択肢の意味が維持されたかを点検する。
翻訳レビューと解答の技術的検証は別。訳せたことを原教材の全解答が正しいことと混同しない。translations/checkpoint.jsonで未処理・翻訳済み・要確認を管理する。

## 図表・講義・補足
旧Question Archiveの図表は再描画。原図を優先するなら別冊Diagrams_JAまたはそのZIP内PNGを使う。図表IDと元カードIDで関連付け、ファイルの順番で推測しない。
assetsは原図＋altJa＋sourceFigureId＋表示位置（stemまたはexplanation）。解説だけの図を解答前に表示して正解が分かる状態を避ける。PDF表紙写真は問題図扱いしない。
CCDV-Fの補足講義10件はlessons配列に保持。問題へ水増ししない。導入・要点・配点の原表記・図表IDを省略しない。
Schema外の原教材フィールドもsupplementalまたはsource内で保持し、黙って破棄しない。

## 重複と矛盾
出典＋資格＋原ID一致は同一問題。本文の完全一致と意味の類似はduplicateGroupIdで別扱い。異なる教材の似た設問を自動削除しない。分野成績が類似問題で水増しされないよう、グループから1問ずつ出す設定を用意する。
CCDV-F Matthew5.9は既知の隔離候補。原文と原解答を保持し、reviewNotesへ矛盾を記録する。解答根拠の確認後にrevisionを更新して解除する。採点対象外は不足件数の中で報告する。

## ZIP・取り込み・バックアップ
問題パックZIP：pack.json、assets/以下のPNG/JPEG/WebP。ファイル参照はZIP内相対パスのみ。JSON単体も可（画像なし、または不足として警告）。外部URL画像・絶対パス・../・重複パス・SVG・スクリプトを拒否。ZIP展開の合計容量・ファイル数・画像サイズに上限を設け、超過時は既存データを変更しない。
インポート：全検証→件数・上書き候補のプレビュー→原子的保存。既存question.idかつ同revision・同hashなら重複追加しない。同revision・異内容は衝突として停止。更新は旧セッションのスナップショットを保つ。
完全バックアップZIP：backup.json（schemaVersion/appId/exportedAt/パック/問題/学習メモ/全セッション/回答/進行状態）と画像。復元はappendまたは明示的置換。answerId/sessionIdの重複を排除し、同ID異内容を警告する。破損時のロールバックを検証する。
教材のみと履歴込みを選んで書き出せる。export時の本文ハッシュや画像チェックサムを検証する。ブラウザ依存のobject URLは保存しない。
